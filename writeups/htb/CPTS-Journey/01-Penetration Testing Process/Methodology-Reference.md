# Penetration Testing Process

## Overview

This module introduces the standard penetration testing methodology used throughout security assessments. Understanding each phase ensures engagements are performed in a structured, repeatable, and professional manner.

---

## Phases

### 1. Pre-Engagement

- Define the scope
- Identify targets
- Establish rules of engagement
- Obtain authorization

### 2. Information Gathering

- Passive reconnaissance
- Active reconnaissance
- Asset discovery
- OSINT

### 3. Enumeration

- Service discovery
- Version detection
- User enumeration
- Share enumeration

### 4. Vulnerability Assessment

- Identify weaknesses
- Validate findings
- Prioritize vulnerabilities

### 5. Exploitation

- Gain initial access
- Verify vulnerabilities
- Maintain stability

### 6. Post-Exploitation

- Privilege escalation
- Credential harvesting
- Lateral movement
- Data collection

### 7. Reporting

- Executive summary
- Technical findings
- Risk ratings
- Remediation recommendations

---

## Key Takeaways

- Follow a structured methodology.
- Enumerate before exploiting.
- Document every finding.
- Minimize impact on production systems.
- Always stay within the agreed scope.
