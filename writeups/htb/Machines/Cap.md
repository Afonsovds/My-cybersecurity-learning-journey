# HTB - Cap (Easy)

## Overview
The **Cap** machine on Hack The Box is an easy-difficulty Linux target focused on enumeration, identifying information disclosure, and leveraging Linux capabilities for privilege escalation.

---

## Reconnaissance
I started by performing a reconnaissance scan against the target using `nmap` to identify open ports and exposed services.

During enumeration, I discovered multiple accessible services that provided useful information about the target environment and guided the next stages of the assessment.

---

## Exploitation and Initial Access
While investigating the exposed functionality, I identified an **information disclosure issue** that allowed access to sensitive data generated by the application.

By analyzing the retrieved information, I was able to obtain valid credentials and successfully gain **initial access** to the machine as a low-privileged user.

---

## Privilege Escalation
After establishing a foothold, I conducted local enumeration to identify possible privilege escalation vectors.

During this process, I reviewed:
- User permissions and privileges
- System configurations
- Existing binaries and their capabilities

After identifying a misconfigured binary with elevated capabilities, I leveraged it to escalate privileges and obtain **root access**.

---

## Root Flag
With full administrative privileges, I accessed the root directory and retrieved the final flag, successfully completing the machine.

---

## Learning Outcomes
- Network and service enumeration using nmap
- Identifying and leveraging information disclosure vulnerabilities
- Using exposed credentials to gain initial access
- Enumerating Linux systems for privilege escalation opportunities
- Exploiting Linux capabilities to obtain root privileges
